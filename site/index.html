04 / BEFORE YOU BEGIN

A few good
questions.

Know what this project covers before you change your device.

Is this for the 2023 onn. 4K?

No. The 2023 onn. 4K non-Pro is a different device. This guide is for the original 2024 onn. 4K Pro (jarvis / SNA), pictured above. Use the supported model’s product listing and the firmware checks to identify your box.

Does the new 2026 4K Pro work?

No support is provided for the new 2026 hardware. It is untested. The March 2026 security patch and October 2026 test date on this page refer to software and testing on the earlier model.

Will I lose my apps and settings?

Unlocking required a factory reset on the tested unit, erasing apps, accounts, and settings. Installing permanent root afterward preserved the new setup. Back up anything you need before starting.

Is permanent root actually verified?

Yes, on the single tested unit: root returned after a normal reboot with the thumb drive physically removed. The original measurements include the root identity, partition hashes, and Magisk environment checks. This does not establish repeatability on another unit or long-term reliability.

Can I use a different firmware or slot A?

No. Only the exact configuration above with slot _b has been tested. The guide stops on a mismatch. Do not downgrade, switch slots, or bypass checks to force compatibility.

Can I use Windows, macOS, or a shared patched image?

The documented host is Linux x86_64; other host systems are untested. The boot image must be patched on your own target device, following the guide. Do not use another person’s patched image.
